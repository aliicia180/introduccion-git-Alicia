# Pasos para resolver el Ejercicio 2

1. Crear la carpeta `pagina_web` y convertirla en un repositorio Git.

2. Crear la primera página HTML.

3. Añadir el archivo al área de preparación:

```bash
git add .
```

4. Crear el primer commit:

```bash
git commit -m "Primera página html"
```

5. Modificar la página para añadir las 3 ciudades que visitar.

6. Añadir los cambios:

```bash
git add .
```

7. Crear el segundo commit:

```bash
git commit -m "Añadidas 3 ciudades que visitar"
```

8. Añadir la información correspondiente a las ciudades.

9. Volver a preparar los cambios y crear el tercer commit:

```bash
git add .
git commit -m "Añadida información sobre las ciudades a visitar"
```

10. Consultar el historial para comprobar los commits realizados:

```bash
git log
```
