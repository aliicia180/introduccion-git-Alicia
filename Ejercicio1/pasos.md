# Pasos para resolver el Ejercicio 1

1. Crear la carpeta `repositorioLocal` para utilizarla como repositorio local.

2. Entrar en la carpeta desde Git Bash.

3. Inicializar el repositorio:

```bash
git init
```

4. Crear los archivos indicados en el ejercicio.

5. Añadir los archivos al área de preparación:

```bash
git add .
```

6. Crear el primer commit:

```bash
git commit -m "Primer commit"
```

7. Realizar las modificaciones indicadas en el ejercicio.

8. Volver a añadir los cambios:

```bash
git add .
```

9. Crear los nuevos commits correspondientes a las modificaciones.

10. Crear la carpeta `aux/` y comprobar que Git puede ignorarla mediante `.gitignore`.

11. Consultar el historial de commits:

```bash
git log
```

12. Utilizar `git checkout` para volver al primer commit y comprobar el estado anterior del repositorio.
