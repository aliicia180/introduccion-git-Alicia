Pasos para resolver el Ejercicio 1
Crear la carpeta repositorioLocal para utilizarla como repositorio local.
Entrar en la carpeta desde Git Bash.
Inicializar el repositorio:
git init
Crear los archivos indicados en el ejercicio.
Añadir los archivos al área de preparación:
git add .
Crear el primer commit:
git commit -m "Primer commit"
Realizar las modificaciones indicadas en el ejercicio.
Volver a añadir los cambios:
git add .
Crear los nuevos commits correspondientes a las modificaciones.
Crear la carpeta aux/ y comprobar que Git puede ignorarla mediante .gitignore.
Consultar el historial de commits:
git log
Utilizar git checkout para volver al primer commit y comprobar el estado anterior del repositorio.
